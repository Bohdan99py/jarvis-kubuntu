# Jarvis for Kubuntu · 0.15

Системный ассистент с чатом, голосом, быстрыми командами, подключаемыми навыками и памятью, которая учится на разговорах и действиях пользователя. Интерфейс на русском и английском — Qt Quick, фоновая служба — systemd user + D-Bus.

[English README](README.en.md) · [Скачать последний релиз](https://github.com/Bohdan99py/jarvis-kubuntu/releases/latest) · [Сборки GitHub Actions](https://github.com/Bohdan99py/jarvis-kubuntu/actions/workflows/release.yml)

## Установка пакета

Скачайте `.deb` для вашей версии Kubuntu/Ubuntu (24.04 или 26.04, amd64). Откройте его в KDE Discover и нажмите «Установить». Или:

```sh
sudo apt install ./jarvis_0.15.0_ubuntu-26.04_amd64.deb
```

Пакет устанавливает программу, значок, пункт меню KDE, D-Bus activation и пользовательскую службу. Jarvis запускается из меню приложений. Демон запускается при обращении и при следующем входе пользователя в сеанс. Он работает с правами пользователя; пароль администратора требуется только системному менеджеру пакетов при установке/обновлении.

Если ранее ставили исходники в `~/.local`, эта копия имеет приоритет над системной. Перед переходом остановите старую службу и перенесите старые `~/.local/bin/jarvis`, `~/.local/bin/jarvisd`, `~/.local/share/applications/org.jarvis.Jarvis.desktop`, `~/.local/share/dbus-1/services/org.jarvis.Daemon1.service` и `~/.local/share/systemd/user/jarvis.service` в резервную папку. Затем выполните `systemctl --user daemon-reload`. Конфигурацию и память удалять не нужно. Запуск системной версии: `/usr/bin/jarvis`.

## Автозапуск и работа в трее

После установки запустите Jarvis один раз из меню — дальше он сам стартует в трее при каждом входе в систему и работает постоянно:

- пользовательская служба `jarvis-tray.service` (systemd, вместе с графическим сеансом Plasma) перезапускает Jarvis, если он упал; в сеансах без systemd срабатывает запись `~/.config/autostart/jarvis-tray.desktop`;
- закрытие окна только прячет его в трей — запись занятия продолжается; «Выход» в меню значка завершает работу (и служба его не перезапускает);
- при выходе из сеанса Jarvis корректно завершается, начатая запись сохраняется;
- выключается в «Центр управления → Приложение → Запускаться вместе с системой в трее» (или в «Параметры системы → Автозапуск»).

## Быстрые команды

- **Meta+J** — действие «Быстрые команды» в KDE. Если сочетание уже занято или Plasma не назначила его автоматически, выберите Jarvis → Быстрые команды в «Параметры системы → Клавиатура → Комбинации клавиш».
- `jarvis --quick` — компактная строка. Повторный запуск активирует уже открытое приложение через D-Bus.
- **Enter** — отправить вопрос; `/web запрос` — поиск DuckDuckGo в браузере; **Esc** — скрыть строку.
- Кнопки «Память», «Процессор», «Диск» получают локальные данные. «Файлы», «Терминал», «Настройки KDE» открывают соответствующее приложение.
- Значок в системном трее открывает строку или основное окно. Произвольные shell-команды из текста не исполняются.

## Голос

Откройте «Меню → Центр управления → Голос» и включите «Озвучивать ответы». Код, ссылки и таблицы не зачитываются — только то, что сказал бы человек.

**Естественный голос.** Кнопка «Установить естественный голос» ставит [Piper](https://github.com/rhasspy/piper) — нейросетевой синтез речи, который звучит как человек и работает на этом компьютере без интернета (около 200 МБ программа и ~63 МБ каждый голос, проверка контрольной суммы по каталогу Piper). Голоса: русские Дмитрий, Денис, Руслан и Ирина; английские Alan и Alba (британские), Ryan, Amy, Lessac; французские Tom и Siwis — французский голос читает и занятия по французскому. Для каждого языка выберите голос, нажмите «Послушать» и настройте темп. Ответ начинает звучать с первой фразы, пока остальные ещё синтезируются. Без Piper используется Speech Dispatcher (espeak-ng), установленный вместе с пакетом.

Для диктовки нажмите «Установить голос». Эта явная операция устанавливает `vosk==0.3.45` в отдельное пользовательское Python-окружение и скачивает [модель Vosk](https://alphacephei.com/vosk/models) для языка интерфейса (русскую или английскую). Размер модели около 40–45 МБ; ей требуется дополнительная память при работе. После смены языка интерфейса установите модель для нового языка той же кнопкой. Установка не меняет системный Python. После этого распознавание работает без сети.

Нажмите «Микрофон», говорите, нажмите стоп. Озвучивание выбирает русский или английский голос по языку ответа. Запись ограничена 20 секундами. Звук не сохраняется в файл и не отправляется в сеть. Распознанный текст попадает в строку ввода: его можно исправить перед отправкой. Уже отправленный текст обрабатывается обычной маршрутизацией: локальные команды/память/примеры или Claude при настроенном API-ключе. Wake-word и фоновое прослушивание не включены.

Данные голоса: `~/.local/share/jarvis/voice` (или `$XDG_DATA_HOME/jarvis/voice`). Для записи используется стандартное ALSA-устройство `default`; его источник выбирается в аудионастройках KDE.

## Навыки

Навыки — плитки с картинками в «Центр управления → Навыки». Встроены: «Электроника и схемы», «Физика», «Встроенные системы», «Программирование», а также разговор, философия, игры и письмо. Переключатель на плитке действует со следующего запроса, в том числе у демона. Нажмите на плитку — откроется страница навыка:

- **Калькуляторы** — считают прямо на этом компьютере, без интернета, результат меняется по мере ввода. Значения пишутся как в жизни: `4.7k`, `4k7`, `100n`, `2,2 мкФ`, `12В`, `20mA`, `72MHz`. Электроника: закон Ома и мощность, резистор для светодиода (с ближайшим номиналом E24 и мощностью), делитель напряжения (и подбор резистора под нужное Uвых), последовательное и параллельное соединение, законы Кирхгофа (две ЭДС и нагрузка, метод узловых потенциалов с проверкой), RC-цепь, реактивное сопротивление и резонанс, заряд и энергия конденсатора, цветовая маркировка (в обе стороны), NE555, операционный усилитель, провод, батарея, децибелы. Встроенные системы: UART (BRR/UBRR и ошибка скорости), таймер (подбор PSC/ARR), АЦП, подтяжка I2C, системы счисления. Физика: равноускоренное движение, энергия, теплота, закон Кулона, маятник.
- **Формулы** — около сотни: законы Ома и Кирхгофа, Тевенин и Нортон, RC/RL/LC, реактивные сопротивления, диоды и транзисторы, ОУ, стабилизаторы, тепловой расчёт; механика, термодинамика, электричество и магнетизм, колебания, оптика; битовые операции, git, gdb.
- **Ответы** — база готовых ответов (около сотни: законы Кирхгофа, теоремы Тевенина и Нортона, метод узловых потенциалов, транзисторы, MOSFET, ОУ, 555, KiCad, SimulIDE, законы Ньютона, индукция, указатели, RAII, git…). На эти вопросы Jarvis отвечает мгновенно и без сети; без ключа Claude он находит и близкие по смыслу вопросы.
- **Инструкция** — что получает Claude, когда навык включён.

Расчёты работают и в чате: «делитель 12В 10к 4,7к», «резистор для светодиода 5В 20мА», «U=5 R=220», «параллельно 10к 10к», «маркировка 4,7к», «коричневый чёрный красный золотой», «rc 10к 100нФ», «555 10к 100к 10мкФ», «uart 72MHz 115200», «0x3F в двоичную», «посчитай 2*pi*50*100n». Такие сообщения не уходят в Claude.

Навык — декларативный JSON: инструкции для Claude, формулы, ссылки на встроенные калькуляторы и примеры для локальных ответов. Он не запускает код, не получает root и не обучает веса модели. Импортируйте JSON-файл или укажите прямую HTTPS-ссылку. Новые навыки устанавливаются выключенными: откройте плитку, прочитайте инструкцию и включите. При работе через Claude включённые инструкции передаются в Anthropic как часть системного контекста.

Пример `skills-example.json`:

```json
{
  "schema": 1,
  "id": "audio",
  "name": "Аудиотехника",
  "description": "Усилители, фильтры и акустика",
  "image": "electronics",
  "color": "#f07a8f",
  "prompt": "For audio electronics, state the supply, load impedance and expected power before calculating.",
  "tools": ["opamp", "rc", "db"],
  "formulas": [{"title": "Мощность на нагрузке", "formula": "P = U²/R", "note": "U — действующее напряжение"}],
  "examples": [
    {"question": "Что такое класс D?", "aliases": ["усилитель класса d"], "answer": "Импульсный усилитель: выходные транзисторы работают ключами, КПД 85–95 %."}
  ]
}
```

Поля: `image` — картинка плитки (`electronics`, `physics`, `embedded`, `programming`, `philosophy`, `games`, `conversation`, `writing`), `color` — цвет навыка, `tools` — встроенные калькуляторы (`ohm`, `led`, `divider`, `series`, `kirchhoff`, `rc`, `reactance`, `capacitor`, `color`, `timer555`, `opamp`, `wire`, `battery`, `db`, `uart`, `timer`, `adc`, `i2c`, `bases`, `kinematics`, `energy`, `heat`, `coulomb`, `pendulum`), `formulas`, `aliases` — другие формулировки вопроса. До 50 навыков; файл до 160 КБ; инструкция до 6000 символов; до 150 примеров и 100 формул. Импорт не заменяет существующий id. Пользовательские файлы: `~/.local/share/jarvis/skills`. Состояние: `~/.config/jarvis/skills.ini`.

## Файлы, код и схемы

Скрепка рядом с полем ввода (или перетаскивание в чат) прикрепляет до 8 файлов к вопросу:

- **фото и картинки** (PNG, JPEG, GIF, WebP) — плата, осциллограмма, фото схемы; большие уменьшаются до 1568 px;
- **PDF** — даташиты, статьи, схемы: Claude читает текст и страницы;
- **код и текст** — C/C++/Arduino, Python, JS/QML, CMake, Verilog/VHDL, ассемблер, linker-скрипты, SPICE, логи, CSV и др. (до 400 КБ);
- **KiCad** — `.kicad_sch` (через `kicad-cli` Jarvis получает полный список соединений по всем листам и PDF самой схемы; без `kicad-cli` — компоненты и метки), `.kicad_pcb` (посадочные места и цепи по контактным площадкам), `.kicad_pro`, список соединений `.net`;
- **SimulIDE** — `.sim1`/`.simu`: компоненты с параметрами и что соединяет каждая цепь.

Схемы Claude получает как список компонентов и цепей («GND: R1.2, C3.1, U1.8») — так он проверяет соединения по цепям, ищет пропущенные подтяжки, развязку, питание и ошибки. Без ключа Claude Jarvis всё равно покажет состав схемы. Файлы остаются в разговоре на два следующих вопроса, затем Claude видит только их имена.

Код в ответах показывается отдельными блоками с подсветкой синтаксиса и кнопками «Копировать» и «Сохранить файлом» — файл сохраняется в `~/Документы/Jarvis/Files` (имя берётся из ответа: Claude подписывает файлы, например ` ```c main.c `). Текст ответа можно выделять мышью.

## Язык

«Центр управления → Приложение»:

- **Язык интерфейса** — «Как в системе», «Русский» или «English». Переключается сразу, без перезапуска. Системный выбор: русский для локалей ru/uk/be, иначе английский.
- **Язык ответов** — «Как в моём сообщении» (по умолчанию) или всегда русский/английский. Локальные ответы, команды памяти и Claude следуют этому выбору. Сообщение без букв (например, «42») отвечается на языке предыдущего.

Голос: модель распознавания выбирается по языку интерфейса (`vosk-model-small-ru-0.22` или `vosk-model-small-en-us-0.15`), озвучивание — по языку самого ответа. Встроенные навыки показывают английские названия при английском интерфейсе (необязательные поля `name_en`, `description_en`).

## Обучаемая память

Память состоит из трёх частей. Всё хранится в `${XDG_DATA_HOME:-~/.local/share}/jarvis/` (папка 0700, файлы 0600, атомарная запись) и видно в правой панели.

**Примеры** (`learning.json`) — вопрос и правильный ответ. Совпадение без учёта регистра и пунктуации отвечается локально, даже без сети. Похожие вопросы передаются Claude как подсказка; без ключа Claude близкий пример (сходство ≥ 0,6) отвечается локально. Сходство считается по общим словам с учётом их редкости: слово, которое встречается во многих примерах, весит меньше. До 2000 примеров по 4096 символов; Jarvis считает, как часто пример пригодился, и когда память заполнена, освобождает место за счёт самого невостребованного. Учить можно в панели «Синапсы» или прямо в чате:

- «нет, правильно: …» / «no, the correct answer is …» — исправляет ответ на предыдущий вопрос;
- «запомни ответ» / «remember this answer» — сохраняет предыдущий вопрос и ответ.

**Факты о пользователе** (`knowledge.json`, вкладка «Обо мне», до 300) — то, что Jarvis узнал из разговора:

- автоматически из фраз вроде «меня зовут …», «я работаю программистом», «я пользуюсь Kate», «я работаю над …», «I live in …», «I like …» (вопросы и местоимения не считаются);
- по команде «запомни, что …» / «remember that …»;
- от Claude: он помечает важное тегом `<memory>`, Jarvis сохраняет факт и убирает тег из ответа.

- автоматически после разговора: если подключён ключ Claude, через полторы минуты тишины Jarvis отправляет последние реплики (до 12) отдельным запросом и сохраняет найденные устойчивые факты и краткое содержание разговора (не чаще раза в 10 минут);
- из активности: программы, в которых вы провели больше 3 часов, и ваши активные часы.

**Любопытство.** Время от времени (после нескольких сообщений, не чаще раза в 10 минут, каждый вопрос — не чаще раза в месяц) Jarvis сам спрашивает о том, чего ещё не знает: как к вам обращаться, над чем работаете, что делаете в программе, где провели много времени, о частой теме разговора, о цели. Следующее сообщение, если это не вопрос и не просьба, считается ответом и запоминается. Карточка «Мне интересно» на вкладке «Обо мне» показывает следующий вопрос; «Спроси меня в чате» задаёт его сразу. Выключается в «Центр управления → Память».

**Противоречия.** Новое утверждение заменяет старое: «я не люблю джаз» убирает «люблю джаз», «я больше не пользуюсь Kate» / «I no longer use Kate» — факт о Kate.

**Краткое содержание разговоров** («эпизоды», до 150). Jarvis помнит не только кто вы, но и о чём вы говорили: при новом вопросе Claude получает связанные прошлые разговоры и последний разговор, если он был недавно. «О чём мы говорили» / «what did we talk about» отвечает локально; три последних видны на вкладке «Обо мне», лишнее удаляется ×.

**Что важно сейчас.** Claude получает не все факты подряд, а сначала главные (имя, работа, проект, цель, учёба), затем относящиеся к вопросу, затем самые надёжные и свежие — так длинная память помещается в запрос.

Факты передаются Claude в системном контексте, поэтому неверное лучше удалить (× в списке, «забудь …» в чате или «Забыть всё»). Похожее на пароль, ключ API или номер карты не сохраняется. «Что ты обо мне знаешь» отвечает локально.

**Темы разговоров** — частота значимых слов в ваших сообщениях и их совместные упоминания (сами сообщения не сохраняются). Они видны в «Частых темах» и в графе.

Граф показывает до 48 слов: бирюзовые — из примеров, оранжевые — из фактов, фиолетовые — темы разговоров. Слова, которые встречаются вместе, собираются в кластеры. По умолчанию у каждого слова видны две самые сильные связи, кнопка «Все связи» показывает остальные. Нажмите на слово — подсветятся все его связи, а в карточке снизу появятся соседи, по которым можно переходить дальше. Колесо мыши — масштаб, перетаскивание — сдвиг (узлы тоже можно двигать), двойной щелчок — приблизить к слову или показать всё; поиск слова и фильтр по типу (щелчок по легенде) — вверху. Импульсы по связям выбранного слова декоративные; это не веса нейросети.

Выключатель «Учиться на наших разговорах и моих действиях в Jarvis» («Центр управления → Память») останавливает автоматическое обучение; явные «запомни …» и примеры продолжают работать.

## Напоминания, задачи и уведомления

Пишите как говорите — в чате, в быстрых командах или на вкладке «Задачи» панели памяти:

- «напомни завтра в 9 позвонить маме», «через 20 минут проверь сборку», «в пятницу в 10 утра созвон», «20.10 в 18:00 сдать отчёт»;
- повторы: «каждый день в 21:00 принять таблетки», «по будням в 8:30 зарядка», «каждый понедельник в 10 план на неделю»;
- задачи без времени: «добавь задачу купить паяльник»;
- «мои напоминания», «отмени напоминание про созвон», «отметь задачу купить паяльник выполненной», «перенеси напоминание про созвон на завтра в 10»;
- ещё повторы: «по выходным», «по понедельникам и средам», «каждые 2 часа», «каждые 30 минут», «каждые 3 дня», «каждое 5 число», «каждый год 20 октября»; заранее: «за 15 минут до встречи завтра в 10».

На вкладке «Задачи» напоминание меняется кнопкой ✎: текст, новое время словами или быстрыми кнопками (+10 мин, +1 час, сегодня вечером, завтра утром, без времени), повтор — в том числе по выбранным дням недели или каждые N минут/часов/дней. В «Центр управления → Автономность → Напоминания» настраиваются кнопка «Отложить» (5–60 минут), повтор уведомления, пока не нажата «Готово» (каждые 5–30 минут, до трёх раз), что значит «утром», «днём» и «вечером» и звук напоминаний.

Время разбирается на этом компьютере. Если правила его не поняли («после обеда», «перед встречей»), с ключом Claude фразу читает Claude, без ключа Jarvis переспросит «когда?». Claude видит открытые задачи и сам ставит напоминание, когда вы просите о нём в свободной форме; поставленное подтверждается строкой ⏰ под ответом. Задачи — `~/.local/share/jarvis/tasks.json` (0600).

Напоминания приходят уведомлениями KDE от фонового демона — даже при закрытом окне, с кнопками «Отложить на 10 мин» и «Готово». Пропущенные, пока компьютер был выключен, приходят при следующем запуске (не больше пяти сразу). Уведомления подчиняются режиму «Не беспокоить» в Plasma.

**Jarvis сам подаёт голос** («Центр управления → Автономность»): не чаще раза в полчаса, не с 23:00 до 7:00 и не во время игр и видео —

- перерыв после 1–2 часов работы без паузы (нужно отслеживание активности; блокировка экрана считается перерывом);
- французские карточки, которые пора повторить; кнопка открывает карточки;
- любопытный вопрос, если вы давно не общались; «Ответить» открывает чат с вопросом;
- план на утро: напоминания на сегодня, открытые задачи, карточки.

**Ежедневная ревизия памяти** (с ключом Claude): раз в сутки Claude получает факты о вас, краткие пересказы разговоров и частые темы, объединяет дубли, убирает устаревшее и отмечает цели и привычки (не больше 5 объединений, 5 удалений и 3 выводов за раз). Факты, добавленные вручную, не удаляются. Об итогах Jarvis сообщает уведомлением.

Пока окно скрыто, приложение сообщает о готовом ответе, законченной расшифровке, переводе PDF и установке голоса, а дважды в день проверяет, не вышла ли новая версия. Всё это выключается на вкладке «Автономность».

## Специалист по встроенным системам

Навык «Встроенные системы» (включён по умолчанию) делает Jarvis инженером-наставником: микроконтроллеры (STM32, AVR/Arduino, ESP32, RP2040…), прошивки на C/C++ (регистры, прерывания, DMA, таймеры, linker-скрипты), RTOS, интерфейсы (UART, SPI, I2C, CAN, USB), схемотехника и электроника (подтяжки, развязка, питание, ключи на MOSFET, ОУ, защита, чтение даташитов и схем, основы трассировки), отладка (SWD/JTAG, OpenOCD, GDB, осциллограф, логический анализатор). Ответы — с конкретными выводами, регистрами, формулами и единицами, с предупреждениями о типичных ошибках. Частые вопросы («чем SPI отличается от I2C», «зачем развязывающий конденсатор», «как рассчитать резистор для светодиода»…) отвечаются локально и без сети. Помощник в VS Code тоже знает специфику прошивок.

## Французский: занятия, перевод, карточки

Кнопка **Français** в заголовке окна (или меню → «Французский») открывает окно учёбы.

- **Занятия.** «● Запись» пишет микрофон в WAV (16 кГц, моно) в `Документы/Jarvis/French/recordings`; уровень сигнала и время видны во время записи. С галочкой «Расшифровывать во время записи» французские фразы появляются через несколько секунд после того, как прозвучали, а с ключом Claude рядом сразу появляется перевод на русский (можно включить озвучку перевода). Текст на лету — черновик; «Расшифровать» после занятия распознаёт весь файл точнее. «Импорт аудио…» принимает mp3, m4a, ogg, видео и т. п. Каждую фразу можно прослушать (кнопка со временем), выделить слова и добавить в карточки.
- **Конспект и слова.** Claude пишет по-русски конспект занятия — тема, грамматика с примерами, полезные фразы, домашнее задание — и добавляет 8–20 ключевых слов в карточки.
- **Переводчик.** Фраза по-французски → русский (по-русски → французский); «🎤 Сказать по-французски» распознаёт сказанное и переводит. «🔊» произносит текст французским или русским голосом.
- **PDF.** Текст берётся из PDF (`pdftotext`; сканы распознаются Tesseract, если установлен `tesseract-ocr-fra`), Claude переводит по абзацам, результат — новый PDF (двуязычный или только русский) и `.txt` в `Документы/Jarvis/French/pdf`.
- **Карточки** с интервальным повторением (упрощённый SM-2): «Снова / Трудно / Хорошо / Легко» (клавиши 1–4, пробел — показать ответ) отодвигают следующий показ — слово возвращается как раз перед тем, как забылось бы. Перевод при добавлении подставляет Claude. Колода — `~/.local/share/jarvis/vocabulary.json`; Jarvis помнит, что вы учите французский, знает трудные для вас слова и может проверить вас в чате.

Распознавание — Whisper (faster-whisper) на этом компьютере, звук никуда не отправляется. Вкладка «Настройка» → «Установить распознавание» скачивает программу из PyPI (около 450 МБ) и модель с Hugging Face в `~/.local/share/jarvis/study`. По умолчанию — **large-v3-turbo** (~1,6 ГБ): лучше всех распознаёт технический французский и расшифровывает лекцию в несколько раз быстрее её длительности; для фраз на лету рядом ставится small (~480 МБ). Есть и base/small/medium.

**Технический французский.** «Тема занятий» на вкладке «Настройка» — список французских терминов (по умолчанию встроенные системы, электроника, программирование: microcontrôleur, broche, interruption, convertisseur analogique-numérique, condensateur de découplage…), которые Whisper ожидает при расшифровке записи: так он правильно пишет профессиональную лексику. Добавьте слова своих курсов. Фильтр отбрасывает зацикленный текст и «эхо» словаря. Claude при переводе и в конспектах использует принятую русскую терминологию (carte → плата, broche → вывод, masse → земля, CAN → АЦП, но bus CAN → шина CAN), не трогает код, имена регистров и формулы и исправляет по контексту термины, которые распознались с ошибкой. Запись работает и без этого. В Anthropic уходят только тексты (расшифровки, фразы, текст PDF) — для перевода и конспектов.

## Активность: Jarvis видит, чем вы заняты

Выключено по умолчанию. Включается в «Центр управления → Память → Видеть, в каком приложении я работаю» или на вкладке «Активность».

- Демон загружает в KWin небольшой скрипт (`/usr/share/jarvis/kwin/activity.js`). Скрипт сообщает по D-Bus только активное окно: класс приложения, файл `.desktop` и заголовок. Работает в Plasma 5 и 6, X11 и Wayland. При выключении или остановке демона скрипт выгружается.
- Учитывается время по приложениям и категориям (программирование, браузер, терминал, общение и т. д.), часы дня, переходы между приложениями и последние окна. Пока экран заблокирован или после 15 минут без смены окна/заголовка время не считается. По дням данные хранятся 14 дней (`activity.json`).
- Заголовки окон сохраняются только с отдельного разрешения. Окна приватного просмотра и менеджеров паролей пропускаются.
- Действия в Jarvis (кнопки быстрой строки, запуск приложений, поиск — без текста запроса) запоминаются. По ним и по привычкам в это время суток в быстрой строке появляются подсказки (★ действие, ▶ приложение).
- В чате: «что я делаю», «чем я занимался сегодня» / «what am I doing», «what did I do today» — отвечается локально.
- «Сообщать Claude, чем я занят» (отдельный выключатель) добавляет активное приложение и сводку дня к запросам в Anthropic.

Если служба стартовала раньше Plasma (обычно при входе в систему), демон ждёт появления KWin и подключается сам; после перезапуска KWin скрипт загружается снова. Отчёты об окнах принимаются только от процесса, которому принадлежит имя `org.kde.KWin`. Вне Plasma отслеживание не работает; остальная память работает.

## Программирование и VS Code

Вкладка «Код» → «Установить расширение VS Code» ставит расширение Jarvis (`code --install-extension`, файл `/usr/share/jarvis/vscode/jarvis-vscode.vsix`). После «Developer: Reload Window» в строке состояния VS Code появится Jarvis.

- **Где искать:** значок Jarvis на боковой панели VS Code (все действия, состояние подключения и Claude, история ответов), «Jarvis» в строке состояния или `Ctrl+Alt+J` (меню действий — у каждого написано, что ему нужно), правый щелчок → Jarvis, лампочка на ошибке (`Ctrl+.`) → «Разобрать ошибки — Jarvis», `Ctrl+Alt+K` — вопрос. Пошаговое знакомство: «Справка → Начало работы → Знакомство с Jarvis».
- **Действия:** спросить о коде, объяснить выделенное, исправить (с кнопкой «Сравнить» — ваш файл и исправленный рядом), написать тесты, добавить комментарии, ревью всего файла, разобрать ошибки, научить Jarvis решению. У каждого блока кода в ответе — «Заменить выделенное»/«Вставить у курсора», «Копировать», «Новый файл».
- **Уроки.** Исправления и разборы ошибок от Claude, ответы с 👍 и фрагменты, которым вы научили, сохраняются как «уроки». При похожей ошибке (ошибки сравниваются без имён и чисел) урок передаётся Claude как проверенное решение, а без ключа Claude — сразу выдаётся ответом. 👎 удаляет урок.
- **Что Jarvis узнаёт сам** (настройка `jarvis.learnFromCoding`): время по языкам и проектам, фреймворки из файлов проекта (CMakeLists.txt, package.json, requirements.txt, pyproject.toml, Cargo.toml, platformio.ini…), частые ошибки компилятора. Языки, фреймворки и проект становятся фактами «Обо мне».
- Код отправляется в Claude только по вашей команде. Связь — через сокет `$XDG_RUNTIME_DIR/jarvis-ide.sock` (права 0600, демон проверяет UID подключившегося процесса).

## Ещё о самообучении

- 👍 под ответом в чате сохраняет его как пример (повторится и без интернета); 👎 — Jarvis спросит, как правильно, и запомнит ваш следующий ответ.
- «Что ты узнал сегодня» — список новых фактов и уроков за день.
- Слабые автоматически выученные факты, которые не подтверждались 90 дней, забываются.

## Защита

- Служба `jarvis.service` работает в песочнице systemd: система и домашняя папка доступны только для чтения, запись — лишь в `~/.local/share/jarvis` и runtime-каталог; без capabilities, с `NoNewPrivileges`, `MemoryDenyWriteExecute`, ограничением пространств имён и семейств сокетов.
- В память не попадает похожее на пароли, ключи и номера карт, а также разметка и фразы-инструкции («ignore previous instructions», «игнорируй…»): факты возвращаются в системный промпт Claude. Заголовки окон очищаются от разметки перед отправкой.
- Фоновый разбор разговора и факты передаются Claude как данные; модель явно предупреждена не выполнять инструкции из них.
- Обновления: URL пакета привязан к репозиторию, проверяются размер, SHA-256 из GitHub API и метаданные `.deb`; установка — только через Discover с подтверждением.

## Обновление одной кнопкой

«Центр управления → Приложение → Обновить Jarvis» проверяет публичные GitHub Releases, выбирает пакет под выпуск Ubuntu и архитектуру, проверяет SHA-256 из GitHub API и метаданные `.deb`, затем открывает Discover. Системную установку подтверждает пользователь. После установки доступны кнопки перезапуска службы и приложения. Не выполняется скрытая установка от root, не запускаются удалённые shell-скрипты.

Первый опубликованный релиз нужен, чтобы эта кнопка начала находить пакеты. До появления релиза, при ошибке сети, отсутствии checksum или несовместимой платформе она показывает ошибку. Более старые версии не устанавливаются. Пока выпускаются пакеты amd64 для 24.04/26.04.

## GitHub Actions: выпуск новой версии

Workflow `.github/workflows/release.yml` строит две версии пакета, выполняет тесты и сохраняет артефакты. Чтобы выпустить следующую версию:

1. Обновите `project(jarvis VERSION …)` в `CMakeLists.txt` и сохраните изменения в GitHub.
2. Actions → Build and release Jarvis → Run workflow → включите **publish**.
3. После успешных проверок появится Release `v<версия>` с двумя `.deb` и контрольными суммами. Можно также отправить тег `v<версия>`.

Уже опубликованные версии не перезаписываются. На pull request публикация недоступна. Используется штатный `GITHUB_TOKEN`; личный токен в репозиторий не нужен. API-ключи, память и голосовые модели в Git не входят.

## Сборка для разработки

```sh
sudo apt install build-essential cmake ninja-build dpkg-dev qt6-base-dev qt6-declarative-dev qt6-declarative-dev-tools qt6-l10n-tools \
  qml6-module-qtquick qml6-module-qtquick-controls qml6-module-qtquick-layouts qml6-module-qtquick-templates \
  qml6-module-qtquick-window qml6-module-qtquick-dialogs qml6-module-qtqml-workerscript qml6-module-qt-labs-platform \
  python3 python3-venv python3-speechd alsa-utils poppler-utils speech-dispatcher speech-dispatcher-espeak-ng espeak-ng
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_INSTALL_PREFIX=/usr
cmake --build build -j 4
ctest --test-dir build --output-on-failure
JARVIS_TEST_BUILD="$PWD/build" dbus-run-session --config-file=tests/test-bus.conf -- python3 tests/integration.py
cpack --config build/CPackConfig.cmake -B dist
./build/jarvis
```

Перевод: исходные строки в коде английские, русский перевод — `i18n/jarvis_ru.ts`. После изменения строк обновите файл и переведите новые сообщения (тест `translations` проверяет полноту):

```sh
/usr/lib/qt6/bin/lupdate -locations none -no-obsolete *.cpp *.h *.qml -ts i18n/jarvis_ru.ts
```

Снимок интерфейса без дисплея (для проверки вёрстки): `QT_QPA_PLATFORM=offscreen JARVIS_UI_SNAPSHOT=shot.png JARVIS_UI_SNAPSHOT_SAY="текст ответа" dbus-run-session --config-file=tests/test-bus.conf -- ./build/jarvis`.

Разработческий демон рядом с установленным: `JARVIS_DBUS_SERVICE=org.jarvis.DaemonDev ./build/jarvisd` (GUI всегда обращается к `org.jarvis.Daemon1`).

D-Bus `org.jarvis.Daemon1`: `Ask`, `Teach`, `Graph`, `Memory` (JSON фактов, тем, активности и настроек), `Remember`, `Forget` (id факта, `facts` или `activity`), `AskFiles` (вопрос и пути к файлам), `RecordAction`, `AddTask` (фраза → напоминание или задача), `TaskAction` (id и `done`/`remove`/`snooze`/`reopen`), `WindowActivated` (вызывает KWin-скрипт), `ReloadConfig`, `Version`, `Quit`; сигналы `Reply`, `Progress` (ответ по мере написания), `MemoryChanged`, `ActivityChanged`.

Qt 6.4+, C++17, Python 3.10+. Сборка под 26.04 не предназначена для 24.04: используйте соответствующий артефакт. Код для распознавания проверяется без доступа к микрофону; реальную работу микрофона и системной горячей клавиши проверяйте в KDE-сеансе.
