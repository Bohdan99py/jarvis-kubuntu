# Аудит настроек перед 0.21

Состояние на коммите `d7521b1` (0.20.0). Проверено по коду, а не по номеру версии.

## Где живут настройки

| Хранилище | Что в нём | Кто пишет | Кто читает |
|---|---|---|---|
| `~/.config/jarvis/config.json` (0600, каталог 0700) | ключ Claude, модель, языки, память, активность, осведомлённость, уведомления, напоминания, фоновая работа, интеграция с Plasma, `desktop` (тема, док, ядро) | `AppSettings` (окно), `DesktopShell` (режим) | `jarvisd` (по `ReloadConfig`), окно, виджеты Plasma через `jarvisd` |
| `~/.config/Jarvis/jarvis.conf` (QSettings) | качество HUD, панель памяти, компактное ядро, голос вкл./выкл., автозапуск настроен, видеокарта и графический API, подсказка трея, словарь и модель «Учёбы» | `AppSettings`, `VoiceController`, `GraphicsInfo`, `DesktopController`, `StudyController` | только окно |
| `~/.local/share/jarvis/voice/speech.json` | движок голоса, голоса Piper, темп, ElevenLabs (ключ, голос, модель, стабильность), Chatterbox | `VoiceController` | окно, `scripts/speak.py` |
| `~/.config/jarvis/skills.ini` | включённые навыки | `SkillStore` | окно, служба |
| `~/.config/plasma-org.kde.plasma.desktop-appletsrc` | панель дока (высота, край, выравнивание, автоскрытие) и настройки самого дока (`main.xml`: закреплённые, размер значков, увеличение, стекло, состав) | Plasma; `DesktopShell::apply/update` через скрипт Plasma | Plasma |
| Портал GlobalShortcuts / kglobalaccel | Ctrl+J (оверлей, компонент `org.jarvis.Jarvis`), Meta+J (быстрые команды, `org.jarvis.Jarvis.desktop` → `Quick`) | KDE | KDE |
| systemd user | `jarvis-tray.service` (автозапуск окна), `jarvis.service` | `DesktopController::setAutostart` | systemd |

## Найденные проблемы

1. **Две точки входа и разбросанные настройки.** Ключ и модель — в отдельном диалоге, веб-поиск — среди навыков, горячая клавиша — в «Осведомлённости», автозапуск — в «Рабочем столе», язык и HUD — в «Приложении». Поиска нет. Центр — диалог внутри главного окна (800×700), его не открыть без главного окна.
2. **Секреты открытым текстом.** Ключ Claude лежит в config.json, ключ ElevenLabs — в speech.json (0600). В сеансе есть Secret Service (`org.freedesktop.secrets`, ksecretd/KWallet), но Jarvis его не использует.
3. **Потеря настроек при записи.** `Config::save` пишет только известные ему поля — неизвестные (от будущей или другой версии) пропадают. Повреждённый config.json читается как «всё по умолчанию», и первая же запись затирает файл.
4. **Устаревшее значение в интерфейсе.** Переключатели и списки теряют привязку после щелчка: если запись не удалась, элемент показывает несохранённое значение. Изменения файла извне (служба, `jarvis --desktop-mode`, второй экземпляр) окно не видит.
5. **Док в двух местах.** Изменение высоты или края панели в режиме правки Plasma не попадает в config.json, а центр показывает старое значение. Настройки самого дока (значки, увеличение, стекло) в центре отсутствуют.
6. **Параметр без поддержки:** `desktop.dockAllScreens` нормализуется и хранится, но ничего не делает (в интерфейс не выводится и в 0.21 тоже не выводится).
7. **Подключение не проверить.** Модель — свободное поле без проверки, ошибка ключа видна только при первом вопросе.
8. **Горячие клавиши.** Нет списка, нет сообщений о конфликте; Meta+J не меняется из Jarvis.
9. **Нет переходов в модули KDE** (звук, Bluetooth, сеть, экраны и т. д.).
10. **Нет сброса**: ни раздела, ни всех настроек. «Очистить историю активности» удаляет данные без подтверждения.
11. **Непонятные подписи:** «Фоновая работа», «Интеграция с Plasma», «Interface»/«Интерфейс» (на деле качество HUD), «Любопытство: …», «Начинать с системой в трее и продолжать работать».
12. Учёта расхода токенов нет (клиент не сохраняет `usage`) — страница расхода в 0.21 не показывается. Журнала действий тоже нет; есть только счётчики предложений за 30 дней.

## Решения для 0.21

- Одно окно «Настройки Jarvis» (отдельное окно, не диалог) с разделами, поиском и сбросом; старый диалог API и вкладки центра управления встроены в него.
- Хранилище остаётся прежним (config.json, jarvis.conf, speech.json, appletsrc). Секреты переезжают в Secret Service; если его нет — остаются в config.json/speech.json, и интерфейс прямо пишет «в файле, доступном только вам».
- `config_version: 2`, резервная копия перед миграцией, сохранение неизвестных полей, отложенная копия повреждённого файла.
- Док: панель и настройки апплета читаются из Plasma и пишутся в Plasma; config.json синхронизируется с панелью.
