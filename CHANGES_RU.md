# Jarvis 0.13 — напоминания, уведомления и автономность

- Напоминания и задачи обычными фразами: «напомни завтра в 9 позвонить маме», «через 20 минут проверь сборку», «по будням в 8:30 зарядка», «добавь задачу купить паяльник», «мои напоминания», «отмени напоминание про …». Время разбирается локально; непонятное («после обеда») читает Claude, без ключа Jarvis переспрашивает. Claude видит открытые задачи и ставит напоминания по просьбе в свободной форме. Вкладка «Задачи» в панели памяти.
- Уведомления KDE: напоминания от демона даже при закрытом окне (отложить на 10 минут, готово, пропущенные — при следующем запуске); готовый ответ, расшифровка, перевод PDF и установка голоса, пока окно скрыто; новая версия Jarvis.
- Автономность («Центр управления → Автономность»): Jarvis сам подсказывает сделать перерыв, повторить французские карточки, присылает любопытный вопрос и план на утро — не чаще раза в полчаса, не ночью и не во время игр и видео.
- Ежедневная ревизия памяти через Claude: объединение дублей, удаление устаревшего, выводы о целях и привычках; ручные факты не удаляются.

# Jarvis 0.12 — быстрее и понятные синапсы

- Скорость: граф синапсов больше не перерисовывается на процессоре 12 раз в секунду (и в трее тоже) — он рисуется только когда что-то меняется; индикатор в шапке анимируется только пока Jarvis думает; пока окна скрыты, память и граф не перечитываются при каждой смене окна, а обновляются, когда окно открыто.
- Синапсы: раскладка по смыслу — слова одного примера или темы в своём кластере; по умолчанию видны две сильнейшие связи каждого слова, «Все связи» — остальные.
- Клик по слову подсвечивает его связи и показывает карточку с соседями, по которым можно переходить; масштаб колесом, сдвиг перетаскиванием, перетаскивание узлов, двойной щелчок — приблизить или показать всё, кнопки +/−/⤢.
- Поиск слова на графе, фильтр по типу щелчком по легенде; при обновлении памяти слова остаются на своих местах.

# Jarvis 0.11 — всегда в трее и специалист по встроенным системам

- Автозапуск в трее при входе в систему (служба systemd `jarvis-tray.service` с перезапуском после сбоя, запасной XDG-автозапуск); закрытие окна прячет Jarvis в трей, запись занятия продолжается; корректное завершение при выходе из сеанса. Переключатель в «Центр управления → Приложение».
- Навык «Встроенные системы»: микроконтроллеры, прошивки, RTOS, интерфейсы, схемотехника, электроника, отладка; локальные ответы на частые вопросы. Экспертиза по прошивкам и в помощнике VS Code.
- Технический французский: модель large-v3-turbo по умолчанию (small для фраз на лету), словарь терминов «Тема занятий» для Whisper, фильтр зацикливаний, русская инженерная терминология в переводе и конспектах.

# Jarvis 0.10 — французский и память, которая помнит разговоры

- Окно «Французский»: запись занятий с расшифровкой французской речи на лету (Whisper, на этом компьютере) и переводом на русский, импорт аудио и видео, прослушивание каждой фразы, точная расшифровка всего файла.
- Конспект занятия по-русски от Claude: тема, грамматика, полезные фразы, домашнее задание — и ключевые слова сразу в карточки.

- Карточки слов с интервальным повторением; Jarvis знает трудные для вас слова и может проверить вас в чате.
- Память: краткое содержание разговоров и «о чём мы говорили»; Claude получает самые важные для вопроса факты; новое утверждение заменяет противоречащее старому («я больше не пользуюсь …»); обученные ответы считают, как часто пригодились, лимит — 2000.

# Jarvis 0.8 — любопытство и автоматическая память

- Любопытство: Jarvis сам задаёт вопросы о вас, о частых темах и о программах, где вы проводите много времени, и запоминает ответы. Карточка «Мне интересно» и кнопка «Спроси меня в чате».

- Защита: отчёты об окнах только от KWin, песочница systemd, фильтр разметки и инструкций в памяти, очистка заголовков окон, системный Python для вспомогательных скриптов, отдельный KWin-скрипт для тестового демона.
- Исправлено: сообщения обновления на языке интерфейса, приветствие при смене языка, запись действия при занятом Jarvis, обрывки тегов `<memory>` в ответах.

- Интерфейс на английском и русском, переключение без перезапуска; язык ответов — как в сообщении или всегда RU/EN. Английская модель распознавания речи, озвучивание на языке ответа.

# Jarvis 0.5 — системный ассистент с обучаемой памятью

Два процесса: Qt Quick интерфейс и фоновый jarvisd. Закрытие окна не останавливает установленный демон. Данные системы читаются локально, произвольные вопросы обрабатываются Claude при наличии ключа. Демон работает с правами текущего пользователя; запуска произвольных shell-команд и административных операций в этой версии нет.

## Обучение

В правой панели введите вопрос и правильный ответ, нажмите «Создать связи». Задайте этот вопрос в чате: ассистент ответит из памяти, в том числе без интернета. Регистр, лишние пробелы и пунктуация не влияют на совпадение. Повторное сохранение вопроса заменяет ответ. Запросы о текущем состоянии системы имеют приоритет над памятью.

Это обучение через явно заданные примеры, а не обучение весов нейросети. Семантического поиска и самостоятельного обучения пока нет. Диалоги автоматически в учебную память не записываются. Учебные примеры сами по себе в Claude не передаются; обычные вопросы, которые не обработаны локально, могут отправляться в Claude согласно существующей маршрутизации.

Граф показывает слова длиной более двух символов и их совместное появление в примерах. Толщина ребра соответствует числу примеров со связью, выбор узла подсвечивает связи. Движение импульсов — визуальная анимация, не показатель нейронных вычислений. Отображаются 48 самых частых слов, до 20 разных слов на пример. Никаких демонстрационных узлов нет.

Хранилище: `${XDG_DATA_HOME:-~/.local/share}/jarvis/learning.json`, атомарная запись, права файла 0600. До 500 примеров, вопрос и ответ до 4096 символов. GUI в локальном режиме использует тот же файл. Для удаления памяти остановите демон, закройте GUI и удалите этот файл. «Очистить чат» учебную память не удаляет.

## Сборка и установка

Из этой папки:

```sh
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build -j 4
./build/jarvis
```

Установка в домашний каталог:

```sh
cmake --install build --prefix "$HOME/.local"
systemctl --user daemon-reload
systemctl --user enable --now jarvis.service
```

При обновлении уже установленного демона:

```sh
systemctl --user restart jarvis.service
```

Установленный демон доступен через session D-Bus. Новые методы `Teach(s,s) -> s` (пустая строка означает успех) и `Graph() -> s` (JSON). UI использует асинхронные вызовы. Если установлен старый демон, его нужно обновить вместе с GUI.

Сервис имеет NoNewPrivileges, приватный /tmp и UMask=0077. Чтобы продолжать работу после выхода пользователя из сеанса, отдельно настройте linger для пользователя средствами systemd. Эта настройка автоматически не выполнялась.

## Проверка

Сборка C/C++ и QML, запуск Qt Quick вне экрана, интеграционная проверка Teach/Graph/Ask на изолированной D-Bus шине: валидация, замена ответа, права файла, память после перезапуска и нормализация вопроса.

Сценарий находится в tests/integration.py. Запуск после сборки из корня проекта:

```sh
JARVIS_TEST_BUILD="$PWD/build" dbus-run-session --config-file=tests/test-bus.conf -- python3 tests/integration.py
```
