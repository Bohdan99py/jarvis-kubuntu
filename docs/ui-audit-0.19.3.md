## Оверлей (Ctrl+J)

Ctrl+J / `jarvis --overlay` открывает, Esc закрывает (или останавливает ответ), Ctrl+E — развернуть, Ctrl+Shift+S — экран; кнопка развёртывания, копирование ответа, микрофон в композере; один разговор с окном (новая сессия не создаётся). Проверено во вложенной сессии: компактный вид сверху (не перекрывает нижний док), ввод, развёрнутый вид, закрытие.

## Центр управления → Рабочий стол

Положение, размер и **выравнивание** дока, автоскрытие, замена панелей, эффекты → `setDesktop` + `shell.update()` (скрипт Plasma, без перезапуска); профили: рабочий стол, программы (чипы, поиск установленных, ×), файлы «подготовки», виджеты, **уровень активности Jarvis**, «Переключить», «Подготовить» → `setProfile` / `switchWorkspace`; ошибки показываются строкой отчёта (`center.report`). Сохраняется в `config.json` (`desktop`) и `workspaces.json`.
